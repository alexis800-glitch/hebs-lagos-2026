# Brand assets — source of truth

This folder holds original, unmodified brand artwork as supplied by the client.
It is **not** inside `public/`, so nothing here is served to browsers or shipped
in the deployment bundle. Pages always render an optimized derivative instead.

## Derivatives in use

All derivatives are produced by uniform scaling of the alpha-trimmed artwork.
The design is never redrawn, recoloured or stretched, and the visible artwork is
never cropped — only the fully transparent outer margin is removed.

| Asset | Size | Purpose |
|---|---|---|
| `public/assets/logos/hebs-lagos-2026-logo-nav.png` | 641 × 600 | Header / navigation logo |
| `app/icon.png` | 512 × 512 | Favicon (PNG) |
| `app/apple-icon.png` | 180 × 180 | iOS home-screen icon |
| `app/favicon.ico` | 16/32/48/256 | Legacy favicon |

The square icons centre the trimmed artwork at 92% of the canvas. Aspect ratio
of the trimmed artwork is 1.0683 (w/h) and is preserved in every derivative.
