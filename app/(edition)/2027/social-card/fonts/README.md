# Social card fonts

Static instances of the site's two typefaces, for `/2027/social-card` (the card
renderer reads TTF, not the site's variable WOFF2 files). Made with fontTools
4.55.3 from `app/(edition)/2027/concepts/_fonts` (Fontsource 5.2.5):

| File | Source | Instance |
| --- | --- | --- |
| bodoni-moda-500.ttf | bodoni-moda-latin-opsz-normal.woff2 | opsz 28, wght 500 |
| bodoni-moda-italic-400.ttf | bodoni-moda-latin-opsz-italic.woff2 | opsz 28, wght 400 |
| jost-500.ttf | jost-latin-wght-normal.woff2 | wght 500 |

Both families are under the SIL Open Font License 1.1 (OFL-*.txt here).
